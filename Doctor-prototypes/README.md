# Doctor Prototypes

Static healthcare prototype showcase containing three clickable demos:

- Shashvat Hospital
- Astha Multispeciality Hospital
- Slim 'n Slender Healthcare Management

## Structure

- `index.html`, `style.css`, `script.js`: showcase landing page
- `assets/`: shared landing-page images
- `prototypes/`: independently addressable prototype demos
- `docs/`: prototype notes and deployment guide
- `.github/workflows/deploy.yml`: GitHub to Cloudflare Pages deployment

## Run and validate

Open `index.html` directly for a quick preview, or run `npm run validate` with Node.js 20+ before pushing.

Deployment instructions are in `docs/DEPLOY.md`.
